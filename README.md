# Statistical Business Analysis

## 📊 Statistical Business Analysis using Python

A data analytics project focused on applying **statistical analysis and exploratory data analysis (EDA)** to business datasets. The project analyzes sales performance and customer churn to identify patterns, relationships, trends, and actionable business insights.

---

## 🎯 Project Objective

The main objective of this project is to use statistical methods and data visualization techniques to understand business data and answer important analytical questions such as:

* How are sales distributed across different categories?
* What factors are associated with customer churn?
* Are there meaningful relationships between business variables?
* What patterns can be identified from the data?
* How can statistical analysis support business decision-making?

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/soumya-prasad-1/Statistical_Business_Analysis.git
```

### 2. Navigate to the project

```bash
cd Statistical_Business_Analysis
```

### 3. Install required libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open:

```text
statistical_analysis.ipynb
```

and run the cells sequentially.
